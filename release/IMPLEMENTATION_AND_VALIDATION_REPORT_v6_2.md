# AF v6.2 Implementation and Validation Report

**Release timestamp:** 2026-08-15T09:00:00Z  
**Change class:** Minor publication-integrity, provenance, verification, and deposit-readiness release. No normative semantic expansion.

## 1. Build basis

The verified AF-v6.0 master package was used as the build base. The latest independent critique was adjudicated against the complete package rather than against selected derivatives. Its four substantive blockers - version binding, AF-SB12 divergence, DOCX/Markdown synchronization, and mixed-state Stage A precedence - were already closed in v6.0 and were regression-tested rather than redesigned.

## 2. Genuine v6.2 improvements

1. **Provenance correction.** Removed an exact duplicate with a misleading “final synchronization audit” filename. Retained the raw pre-correction review once under an accurate provenance name and added a true post-correction synchronization audit.
2. **Canonical registry.** Added a machine-readable and human-readable registry for artifact authority, stable component identifiers, Stage A states/statuses, binding precedence, AF-SB12-v5.6, evidence boundaries, and verification paths.
3. **Artifact authority and version policy.** Distinguished package release versions from stable component versions and defined a fail-closed conflict rule.
4. **External fact verification.** Rechecked the contemporary climate, poverty, conflict, and Global Flourishing Study anchors against official or primary sources and recorded claim boundaries.
5. **Active-version synchronization.** Updated active publications, companions, workbook, release records, submission files, schemas, tests, and supplement paths to AF-v6.2 while preserving `AF-SB12-v5.6` and `AF-SB-RELATION-v6.0`.
6. **Portable verification.** Rebuilt the root verifier around ZIP/XML and standard-library inspection, including active-version drift, canonical-registry parity, publication triplets, workbook configuration, navigation, provenance uniqueness, and supplement replay.
7. **Deposit usability.** Added `START_HERE.md`, updated repository metadata, and clarified the package map and verification route.
8. **Full production replay.** Rebuilt PDFs from the current DOCX family, visually inspected all rendered pages and key workbook surfaces, regenerated checksums, and replayed verification from the extracted final ZIP.

## 3. Unchanged semantics

C0-C5, rights/non-compensation, Stage A precedence, status meanings, AF-SB12 dimensions, Stage B relation semantics, the CL0-CL6 legitimacy ladder, and the separation between evaluation and authorization are unchanged.

## 4. Validation boundary

The release is complete at the specification, artifact-integrity, communication, instrument-design, provenance, and release-engineering levels. External empirical validation and independent legitimacy remain open.

This artifact implements the v6.2 three-axis record (`decision_status`, `evidence_state`, `review_state`), the non-erasure invariant, perturbation-replay anti-inflation and anti-suppression controls, and the separation of raw agreement, reliability, adjudication, and external validity.
