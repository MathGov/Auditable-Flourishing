This supplement contains the executable and machine-readable evidence used to verify AF-v6.2.

It includes:

- the AF v6.2 aggregation workbook;
- the controlling Stage A public-status and criterion-state vocabulary, including migration aliases;
- the canonical Stage A precedence;
- a perturbation proposal/admission/replay schema with valid and hostile examples;
- adversarial workbook replay results;
- exact Stage B structural-yield simulation code and outputs;
- an exploratory perturbation-sensitivity simulation with explicit non-controlling assumptions;
- reference logic and tests for Stage A and perturbation admission;
- mixed-state precedence tests ensuring established material defects are not erased by uncertainty elsewhere;
- a self-contained supplement verifier and SHA-256 inventory.

`AF-SB-RELATION-v6.0` is retained as a stable component identifier because its semantics did not change in package release v6.2.

The workbook is an aggregation and analysis instrument, not an immutable rating-deposit system. The supplement establishes internal artifact integrity and executable semantics only. It does not establish reliability, validity, fairness, constitutional legitimacy, legal conformity, decision value, flourishing outcomes, or deployment authorization.
