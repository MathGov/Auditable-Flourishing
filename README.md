# Auditable Flourishing v6.2

**Status:** Master specification frozen; publication-integrity and provenance closure complete; Phase 0 design-ready; external validation open.

This master package contains the canonical reference work, journal-facing methods article, all normative companions, figures, the hardened aggregation workbook, reproducibility materials, release records, canonical registry, provenance, official-source fact verification, and independent verification tools.
